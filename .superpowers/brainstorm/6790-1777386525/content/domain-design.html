1 · Backend — Universal Summarization
Extend domain guidance to all 20+ fields — add the 8 missing ones (business, linguistics, political science, sociology, art, music, architecture, etc.) to _SECTION_TOPIC_GUIDANCE.

Dynamic fallback for any unknown topic — if a topic isn't in the dict, inject: "Apply domain-appropriate summarization for a {topic} lecture, focusing on terminology, key concepts, and methodologies specific to this field." Handles niche fields like actuarial science, marine biology, game design — anything.

Topic hint in micro summaries (Phase 1) — currently topic-agnostic. Add a light domain hint so even the 12-second chunk bullets are field-aware.

Result: Any field, any topic — the AI adapts automatically.
2 · Backend — Domain-Aware Q&A
Currently answer_lecture_question() has no domain context. Fix:

• The /ask endpoint fetches topic and passes it to the QA service
• QA system prompt gets: "This is a {topic} lecture. Apply domain-appropriate terminology and reasoning when answering."
• Law Q&A cites principles correctly. Math Q&A uses proper notation. CS Q&A discusses algorithms precisely.
3 · Backend — Manual Topic Override Endpoint
New endpoint: PUT /api/v1/lectures/{id}/topic
Body: {"topic": "law"} — owner-only, updates lectures.topic.

Also: a topic field on the POST /live/start request — so users can declare their domain before the first chunk is processed, not after.
4 · Frontend — Domain Selection UI
Before recording (Start Session modal): optional domain picker — 20 pills to tap + "Other" free text. Skip = auto-detect.

During recording: topic badge (already exists as purple pill) becomes clickable → inline dropdown to correct if auto-detect got it wrong.

LectureView & Import flow: same clickable badge — change domain at any time. Change triggers a re-summarization prompt if summaries already exist.

Dashboard cards: domain badge already shows — no change needed.
5 · Frontend — Domain-Specific Content Rendering
GPT already outputs LaTeX and code blocks — we just don't render them.

Math / Physics / Engineering: add KaTeX — detects $...$ and $$...$$ in summaries, Q&A answers, and Smart Explain output. Renders inline and block equations.

CS / Programming: add highlight.js — detects ``` code fences, renders with syntax highlighting.

Applies to: summary panel, Q&A answers, Smart Explain panel — anywhere AI text is displayed.
